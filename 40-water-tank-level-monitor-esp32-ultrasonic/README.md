# Water Tank Level Monitor with ESP32 and Ultrasonic Sensor (Leak Alert)

Build a rooftop water tank level monitor with ESP32 and a JSN-SR04T or HC-SR04: level % formula, median filter, phone page, night leak alert and moisture tips.

**Full tutorial (wiring table, explanation, troubleshooting):** https://electrodai.com/tutorial/water-tank-level-monitor-esp32-ultrasonic

> ⚠️ Some code here is marked **untested / not yet compiled** in the tutorial. Test on your own board first and report issues.

## Files

- [`water_sketch/water_sketch.ino`](water_sketch/water_sketch.ino)

Arduino sketches: open the `.ino` file in Arduino IDE (each sits in a folder with the same name, as the IDE expects).
