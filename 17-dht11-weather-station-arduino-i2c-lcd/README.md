# DHT11 Weather Station with Arduino and 16x2 I2C LCD

Build a temperature and humidity display with a DHT11, Arduino Uno and 16x2 I2C LCD. Wiring table, commented code and troubleshooting.

**Full tutorial (wiring table, explanation, troubleshooting):** https://electrodai.com/tutorial/dht11-weather-station-arduino-i2c-lcd

> ✅ Every sketch here compiles (checked with Arduino CLI, November 2026). Not all of them have been tested on real hardware yet — try it on your board and [open an issue](https://github.com/electrodai/electrodai-projects/issues) if something does not work.

## Files

- [`dht11_sketch/dht11_sketch.ino`](dht11_sketch/dht11_sketch.ino)

Arduino sketches: open the `.ino` file in Arduino IDE (each sits in a folder with the same name, as the IDE expects).
