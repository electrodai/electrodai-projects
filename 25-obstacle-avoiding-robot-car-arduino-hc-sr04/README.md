# Obstacle Avoiding Robot Car with Arduino and HC-SR04

Build an obstacle avoiding robot car with Arduino, HC-SR04, servo scanning and L298N. Parts, wiring, commented code, testing and fixes.

**Full tutorial (wiring table, explanation, troubleshooting):** https://electrodai.com/tutorial/obstacle-avoiding-robot-car-arduino-hc-sr04

> ✅ Every sketch here compiles (checked with Arduino CLI, November 2026). Not all of them have been tested on real hardware yet — try it on your board and [open an issue](https://github.com/electrodai/electrodai-projects/issues) if something does not work.

## Files

- [`obstacle_sketch/obstacle_sketch.ino`](obstacle_sketch/obstacle_sketch.ino)

Arduino sketches: open the `.ino` file in Arduino IDE (each sits in a folder with the same name, as the IDE expects).
