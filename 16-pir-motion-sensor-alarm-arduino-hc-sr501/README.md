# PIR Motion Sensor Alarm with Arduino (HC-SR501)

Build a motion alarm with an HC-SR501 PIR sensor, Arduino Uno, LED and buzzer. Pin table, commented code, sensor tuning and troubleshooting.

**Full tutorial (wiring table, explanation, troubleshooting):** https://electrodai.com/tutorial/pir-motion-sensor-alarm-arduino-hc-sr501

> ✅ Every sketch here compiles (checked with Arduino CLI, November 2026). Not all of them have been tested on real hardware yet — try it on your board and [open an issue](https://github.com/electrodai/electrodai-projects/issues) if something does not work.

## Files

- [`pir_sketch/pir_sketch.ino`](pir_sketch/pir_sketch.ino)

Arduino sketches: open the `.ino` file in Arduino IDE (each sits in a folder with the same name, as the IDE expects).
