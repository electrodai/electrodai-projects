# Robotic Arm with Servos and Potentiometers (Arduino)

Build a 4-servo robotic arm controlled by potentiometers with Arduino. Separate 5 V servo supply, wiring table, smooth jitter-free code and fixes.

**Full tutorial (wiring table, explanation, troubleshooting):** https://electrodai.com/tutorial/robotic-arm-arduino-servos-potentiometers

> ⚠️ Some code here is marked **untested / not yet compiled** in the tutorial. Test on your own board first and report issues.

## Files

- [`robotic_sketch/robotic_sketch.ino`](robotic_sketch/robotic_sketch.ino)

Arduino sketches: open the `.ino` file in Arduino IDE (each sits in a folder with the same name, as the IDE expects).
