# ESP32 IoT Dashboard with Blynk: Send Sensor Data to Your Phone

Send DHT11 temperature and humidity from an ESP32 to a Blynk dashboard on your phone. Wiring, 3.3V notes, template setup, code and fixes.

**Full tutorial (wiring table, explanation, troubleshooting):** https://electrodai.com/tutorial/esp32-iot-dashboard-blynk-sensor-data-phone

> ⚠️ Some code here is marked **untested / not yet compiled** in the tutorial. Test on your own board first and report issues.

## Files

- [`esp32_sketch/esp32_sketch.ino`](esp32_sketch/esp32_sketch.ino)

Arduino sketches: open the `.ino` file in Arduino IDE (each sits in a folder with the same name, as the IDE expects).
