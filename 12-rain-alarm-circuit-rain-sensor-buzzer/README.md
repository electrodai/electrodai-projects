# Rain Alarm Circuit Using a Rain Sensor and Buzzer (With and Without Arduino)

Build a rain alarm with a rain sensor module and buzzer, first with a BC557 transistor and then with Arduino. Wiring tables, code and fixes.

**Full tutorial (wiring table, explanation, troubleshooting):** https://electrodai.com/tutorial/rain-alarm-circuit-rain-sensor-buzzer

> ⚠️ Some code here is marked **untested / not yet compiled** in the tutorial. Test on your own board first and report issues.

## Files

- [`rain_sketch/rain_sketch.ino`](rain_sketch/rain_sketch.ino)

Arduino sketches: open the `.ino` file in Arduino IDE (each sits in a folder with the same name, as the IDE expects).
