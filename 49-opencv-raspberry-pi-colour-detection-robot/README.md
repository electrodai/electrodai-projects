# OpenCV on Raspberry Pi: Colour Detection for a Robot

Detect a coloured ball with OpenCV on a Raspberry Pi using HSV masks and contours, then steer an Arduino robot over USB serial. Code, tuning and FPS tips.

**Full tutorial (wiring table, explanation, troubleshooting):** https://electrodai.com/tutorial/opencv-raspberry-pi-colour-detection-robot

> ⚠️ Some code here is marked **untested / not yet compiled** in the tutorial. Test on your own board first and report issues.

## Files

- [`step1.py`](step1.py)
- [`step2.py`](step2.py)

Arduino sketches: open the `.ino` file in Arduino IDE (each sits in a folder with the same name, as the IDE expects).
