# Battery Voltage Monitor with Arduino (Voltage Divider, Low Voltage Only)

Measure a 12 V or 7.4 V battery with Arduino A0 using a voltage divider. Formula, wiring table, calibration, low-battery alarm code and fixes.

**Full tutorial (wiring table, explanation, troubleshooting):** https://electrodai.com/tutorial/battery-voltage-monitor-arduino-voltage-divider

> ⚠️ Some code here is marked **untested / not yet compiled** in the tutorial. Test on your own board first and report issues.

## Files

- [`battery_sketch/battery_sketch.ino`](battery_sketch/battery_sketch.ino)

Arduino sketches: open the `.ino` file in Arduino IDE (each sits in a folder with the same name, as the IDE expects).
