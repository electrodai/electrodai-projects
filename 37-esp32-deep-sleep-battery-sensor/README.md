# ESP32 Deep Sleep: Run a Sensor for Months on a Battery

Use ESP32 deep sleep with timer and button wake-up, keep data with RTC_DATA_ATTR, measure sleep current with a multimeter and estimate real battery life.

**Full tutorial (wiring table, explanation, troubleshooting):** https://electrodai.com/tutorial/esp32-deep-sleep-battery-sensor

> ✅ Every sketch here compiles (checked with Arduino CLI, November 2026). Not all of them have been tested on real hardware yet — try it on your board and [open an issue](https://github.com/electrodai/electrodai-projects/issues) if something does not work.

## Files

- [`step3/step3.ino`](step3/step3.ino) — full sketch
- [`snippets.md`](snippets.md) — the short step 1 and step 2 pieces from the article

Arduino sketches: open the `.ino` file in Arduino IDE (each sits in a folder with the same name, as the IDE expects).
