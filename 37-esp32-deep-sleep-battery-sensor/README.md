# ESP32 Deep Sleep: Run a Sensor for Months on a Battery

Use ESP32 deep sleep with timer and button wake-up, keep data with RTC_DATA_ATTR, measure sleep current with a multimeter and estimate real battery life.

**Full tutorial (wiring table, explanation, troubleshooting):** https://electrodai.com/tutorial/esp32-deep-sleep-battery-sensor

> ⚠️ Some code here is marked **untested / not yet compiled** in the tutorial. Test on your own board first and report issues.

- [`step2/step2.ino`](step2/step2.ino)
