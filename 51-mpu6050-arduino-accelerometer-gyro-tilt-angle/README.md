# MPU6050 Accelerometer and Gyro with Arduino: Tilt Angle

Wire an MPU6050 (GY-521) to Arduino over I2C, read raw accelerometer and gyro data, calculate tilt angle with atan2 and smooth it with a complementary filter.

**Full tutorial (wiring table, explanation, troubleshooting):** https://electrodai.com/tutorial/mpu6050-arduino-accelerometer-gyro-tilt-angle

> ⚠️ Some code here is marked **untested / not yet compiled** in the tutorial. Test on your own board first and report issues.

## Files

- [`step1/step1.ino`](step1/step1.ino)
- [`step2/step2.ino`](step2/step2.ino)

Arduino sketches: open the `.ino` file in Arduino IDE (each sits in a folder with the same name, as the IDE expects).
