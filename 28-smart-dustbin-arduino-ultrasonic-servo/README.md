# Smart Dustbin with Arduino, Ultrasonic Sensor and Servo

Build an automatic smart dustbin with Arduino, HC-SR04 and a servo. Wiring table, full code, fullness alert, testing and troubleshooting.

**Full tutorial (wiring table, explanation, troubleshooting):** https://electrodai.com/tutorial/smart-dustbin-arduino-ultrasonic-servo

> ✅ Every sketch here compiles (checked with Arduino CLI, November 2026). Not all of them have been tested on real hardware yet — try it on your board and [open an issue](https://github.com/electrodai/electrodai-projects/issues) if something does not work.

- [`smart_sketch/smart_sketch.ino`](smart_sketch/smart_sketch.ino)

Arduino sketches: open the `.ino` file in Arduino IDE (each sits in a folder with the same name, as the IDE expects).
