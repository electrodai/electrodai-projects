# Landslide Tilt Warning Prototype with MPU6050 and LoRa (Learning Build)

Build a learning prototype that detects tilt with an MPU6050 on an ESP32 and sends alerts over LoRa to a gateway. Wiring, code, testing and limits.

**Full tutorial (wiring table, explanation, troubleshooting):** https://electrodai.com/tutorial/landslide-tilt-warning-prototype-mpu6050-lora

> ⚠️ Some code here is marked **untested / not yet compiled** in the tutorial. Test on your own board first and report issues.

## Files

- [`step1/step1.ino`](step1/step1.ino)
- [`step2/step2.ino`](step2/step2.ino)

Arduino sketches: open the `.ino` file in Arduino IDE (each sits in a folder with the same name, as the IDE expects).
