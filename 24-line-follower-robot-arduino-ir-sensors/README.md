# Line Follower Robot with Arduino and IR Sensors (Complete Build)

Build a line follower robot with Arduino Uno, two IR sensors and an L298N driver. Parts, wiring table, tested logic, code, tuning and fixes.

**Full tutorial (wiring table, explanation, troubleshooting):** https://electrodai.com/tutorial/line-follower-robot-arduino-ir-sensors

> ✅ Every sketch here compiles (checked with Arduino CLI, November 2026). Not all of them have been tested on real hardware yet — try it on your board and [open an issue](https://github.com/electrodai/electrodai-projects/issues) if something does not work.

## Files

- [`step1/step1.ino`](step1/step1.ino)
- [`step2/step2.ino`](step2/step2.ino)

Arduino sketches: open the `.ino` file in Arduino IDE (each sits in a folder with the same name, as the IDE expects).
