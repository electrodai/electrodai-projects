# Automatic Plant Watering with Soil Moisture Sensor and Arduino

Build an automatic plant watering system with a soil moisture sensor, relay and mini pump on Arduino Uno. Wiring, calibration, code and fixes.

**Full tutorial (wiring table, explanation, troubleshooting):** https://electrodai.com/tutorial/automatic-plant-watering-soil-moisture-sensor-arduino

> ⚠️ Some code here is marked **untested / not yet compiled** in the tutorial. Test on your own board first and report issues.

Arduino sketches: open the `.ino` file in Arduino IDE (each sits in a folder with the same name, as the IDE expects).
