# Clap Switch Circuit Using a Sound Sensor Module and Arduino

Build a double-clap switch with a sound sensor module and Arduino Uno. Wiring table, full commented code, calibration steps and fixes.

**Full tutorial (wiring table, explanation, troubleshooting):** https://electrodai.com/tutorial/clap-switch-sound-sensor-module-arduino

> ✅ Every sketch here compiles (checked with Arduino CLI, November 2026). Not all of them have been tested on real hardware yet — try it on your board and [open an issue](https://github.com/electrodai/electrodai-projects/issues) if something does not work.
