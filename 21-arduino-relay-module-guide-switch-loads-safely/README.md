# Arduino Relay Module Guide: Switch Loads Safely

Learn to use a 5V relay module with Arduino to switch a 12V DC lamp or fan. Pinout, COM/NO/NC, active-LOW logic, code and safety rules.

**Full tutorial (wiring table, explanation, troubleshooting):** https://electrodai.com/tutorial/arduino-relay-module-guide-switch-loads-safely

> ⚠️ Some code here is marked **untested / not yet compiled** in the tutorial. Test on your own board first and report issues.

## Files

- [`arduino_sketch/arduino_sketch.ino`](arduino_sketch/arduino_sketch.ino)

Arduino sketches: open the `.ino` file in Arduino IDE (each sits in a folder with the same name, as the IDE expects).
