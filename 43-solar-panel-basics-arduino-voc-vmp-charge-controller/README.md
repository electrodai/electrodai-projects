# Solar Panel Basics for Arduino Projects: Voc, Vmp and Charge Controllers

Read a solar panel label (Voc, Vmp, Isc, Imp), measure a small panel with a multimeter, and charge a battery safely with a charge controller.

**Full tutorial (wiring table, explanation, troubleshooting):** https://electrodai.com/tutorial/solar-panel-basics-arduino-voc-vmp-charge-controller

> ⚠️ Some code here is marked **untested / not yet compiled** in the tutorial. Test on your own board first and report issues.

## Files

- [`solar_sketch/solar_sketch.ino`](solar_sketch/solar_sketch.ino)

Arduino sketches: open the `.ino` file in Arduino IDE (each sits in a folder with the same name, as the IDE expects).
