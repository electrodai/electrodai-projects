# ESP32-CAM Getting Started: Upload, Flash LED and Motion Photo

Upload code to the ESP32-CAM with a USB-serial adapter, fix brownout and Connecting errors, use the GPIO4 flash LED, and take a PIR motion photo.

**Full tutorial (wiring table, explanation, troubleshooting):** https://electrodai.com/tutorial/esp32-cam-getting-started-upload-motion-photo

> ⚠️ Some code here is marked **untested / not yet compiled** in the tutorial. Test on your own board first and report issues.

## Files

- [`esp32_sketch/esp32_sketch.ino`](esp32_sketch/esp32_sketch.ino)

Arduino sketches: open the `.ino` file in Arduino IDE (each sits in a folder with the same name, as the IDE expects).
